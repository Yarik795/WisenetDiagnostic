## **Media events**


Media events are used to receive the camera’s captured audio/video data in different media

formats. Both raw and encoded audio video events are supported. It has the following input events.

#### **Raw video**


The API provides camera captured video to recv_event function in raw video format. YUV422 is the

supported formats.

## **Video analytics events**

event, users need to enable the VA setting in the camera using the WISENET web page. It supports

the following VA events.

to select the Motion Detection event in the VA settings.
