# Запуск Wisenet Диагностика

Инструкция для локального запуска на любой машине. Путь к проекту может быть любым — все команды выполняются **из корня репозитория** (папка, где лежат `backend/`, `frontend/`, `config.example.json`).

Примеры корня проекта:

- `D:\Projects\Wisenet Диагностика`
- `C:\Users\ivan\YandexDisk\Coding\Wisenet Диагностика`
- `/home/user/wisenet-diagnostics`

Далее этот каталог обозначается как **корень проекта**.

---

## Что нужно установить

| Компонент | Версия |
|-----------|--------|
| Python | 3.11 или новее |
| Node.js | 20 или новее |
| npm | идёт вместе с Node.js |

Проверка:

```bash
python --version

```

## 1. Подготовка конфигурации

Перейдите в корень проекта и создайте рабочий конфиг из примера.

**Windows (cmd):**

```cmd
cd /d "ПУТЬ\К\КОРНЮ\ПРОЕКТА"
copy config.example.json config.json
```

**Windows (PowerShell):**

```powershell
Set-Location "ПУТЬ\К\КОРНЮ\ПРОЕКТА"
Copy-Item config.example.json config.json
```

**Linux / macOS:**

```bash
cd "ПУТЬ/К/КОРНЮ/ПРОЕКТА"
cp config.example.json config.json
```

Откройте `config.json` в редакторе и при необходимости укажите:

- `credentials.username` / `credentials.password` — учётная запись SUNAPI для всех NVR;
- `recorders` — список регистраторов (можно оставить пустым и добавить через UI).

> **Важно:** файл `config.json` не попадает в git (содержит пароли). На каждом компьютере его нужно создать заново или скопировать вручную.

Путь к конфигу по умолчанию: `config.json` в корне проекта. Чтобы указать другой файл:

```bash
set CONFIG_PATH=C:\путь\к\my-config.json
```

(Windows) или `export CONFIG_PATH=...` (Linux/macOS) — **перед** запуском backend.

## 2. Backend (API)

Нужен **отдельный терминал**. Все команды — из корня проекта, затем в каталог `backend`.

### Windows (PowerShell)

```powershell
Set-Location "ПУТЬ\К\КОРНЮ\ПРОЕКТА\backend"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Windows (cmd)

```cmd
cd /d "ПУТЬ\К\КОРНЮ\ПРОЕКТА\backend"
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Linux / macOS

```bash
cd "ПУТЬ/К/КОРНЮ/ПРОЕКТА/backend"
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Проверка: в браузере или через curl откройте [http://127.0.0.1:8000/api/health](http://127.0.0.1:8000/api/health) — ответ `{"status":"ok"}`.

Оставьте этот терминал запущенным.

---

## 3. Frontend (веб-интерфейс)

Нужен **второй терминал**. Команды — из корня проекта, затем в `frontend`.

### Первая установка (один раз на машине)

```bash
cd "ПУТЬ/К/КОРНЮ/ПРОЕКТА/frontend"
npm install
```

При ошибках сети (таймаут npm) повторите `npm install` или включите VPN.

### Запуск в режиме разработки

```bash
cd "ПУТЬ/К/КОРНЮ/ПРОЕКТА/frontend"
npm run dev
```

Откройте в браузере: [http://127.0.0.1:5173](http://127.0.0.1:5173)

Запросы к API (`/api/...`) проксируются на `http://127.0.0.1:8000` — backend должен быть уже запущен.

---

## 4. Первый вход в UI

1. Откройте **Настройки** (`/settings`) и сохраните логин/пароль SUNAPI (если не заданы в `config.json`).
2. На **Объектах** (`/objects`) добавьте регистратор: название объекта, host, порт.
3. Нажмите **Проверить** у строки NVR — статус обновится без перезагрузки страницы.

Альтернативный вид — плоский список на **Регистраторах** (`/recorders`).

## Схема запуска

```
Терминал 1 (backend)          Терминал 2 (frontend)
─────────────────────         ─────────────────────
корень/backend                корень/frontend
uvicorn :8000        ←──────  npm run dev :5173
       ↑                              │
       └──────── proxy /api ──────────┘
```

## Сборка frontend для продакшена (опционально)

```bash
cd "ПУТЬ/К/КОРНЮ/ПРОЕКТА/frontend"
npm run build
npm run preview
```

Статика появится в `frontend/dist/`. Для полноценного продакшена обычно настраивают раздачу `dist/` через nginx и проксирование `/api` на backend — на этапе 0 достаточно режима `npm run dev`.

## Частые проблемы

| Симптом | Что проверить |
|---------|----------------|
| UI пустой / ошибка загрузки | Запущен ли backend на порту 8000 |
| `npm install` падает с ECONNRESET | Сеть, VPN, повторить установку |
| Проверка NVR — «Не заданы учётные данные» | Настройки UI или `credentials` в `config.json` |
| Проверка — 401 | Логин/пароль SUNAPI на устройстве |
| Проверка — таймаут | Доступность host:port с этой машины, firewall |
| PowerShell не даёт активировать venv | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
