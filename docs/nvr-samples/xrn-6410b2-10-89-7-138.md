Объёмы в `UsedSpace`/`TotalSpace` — **мегабайты** (числа ~5–6×10⁶). Процент заполнения для UI и матрицы считается суммой по слотам.

## Отличие от XRN-2010 / HRX

Модели с полем `UsedSpace=41.92TB` на корне отдают суммарный процент сразу; XRN-6410B2 и XRN-3210B2 — только по слотам.
