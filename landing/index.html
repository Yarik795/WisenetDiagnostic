01 / Описание

Суть, цели и задачи проекта

Платформа проактивного контроля исправности технических средств охраны — от видеонаблюдения и СКУД до биотерминалов и СОТС — с единым центром данных и управленческой отчётностью для руководителя ТСО.

Цель. Дать руководителю ТСО единую оперативную картину состояния систем безопасности на объектах банка — без ручной сборки отчётов из разрозненных источников.

Задачи:

  • Централизовать данные из АС Арсенал, Naumen, Портала Поставщика, SmartView и CMDB в единой базе
  • Автоматически опрашивать оборудование по API (изначально — реестр из CMDB) и классифицировать исправность по категориям «светофора»
  • Формировать управленческие отчёты: мониторинг, оплата работ, повторные РВР, инвентаризация
  • Применять LLM для анализа повторных заявок и интерактивного запроса данных на естественном языке
  • Обеспечить гибкое добавление новых отчётов из комбинации данных разных систем

«Раньше утро начиналось с пяти Excel-выгрузок. Сейчас открываю один дашборд — сразу вижу, где горит СКУД, где просел архив и какие объекты ждут оплаты СТК.»
