01 / Описание

Суть, цели и задачи проекта

Платформа проактивного контроля исправности технических средств охраны — от видеонаблюдения и СКУД до биотерминалов и СОТС — с единым центром данных и управленческой отчётностью для руководителя ТСО.

Цель. Дать руководителю ТСО единую оперативную картину состояния систем безопасности на объектах банка — без ручной сборки отчётов из разрозненных источников.

Задачи:

  • Централизовать данные из АС Арсенал, Naumen, Портала Поставщика, SmartView и CMDB в единой базе
  • Автоматически опрашивать оборудование по API (изначально — реестр из CMDB) и классифицировать исправность по категориям «светофора»
  • Формировать управленческие отчёты: мониторинг, оплата работ, повторные РВР, инвентаризация
  • Применять LLM для анализа повторных заявок и интерактивного запроса данных на естественном языке
  • Обеспечить гибкое добавление новых отчётов из комбинации данных разных систем

«Раньше утро начиналось с пяти Excel-выгрузок. Сейчас открываю один дашборд — сразу вижу, где горит СКУД, где просел архив и какие объекты ждут оплаты СТК.»

05 / Инновационность · LLM

Искусственный интеллект в ядре аналитики

LLM подсвечивает возможные повторные РВР и отвечает на вопросы к базе данных. Финальное решение — за инспектором: в отчёте можно раскрыть тексты заявок и проверить гипотезы вручную.

LLM · Анализ РВР

Анализ повторных РВР

Модель читает тексты заявок Naumen, присваивает вердикт и формирует свод проблем на объекте. Это подсказка, а не приговор — цифры в матрице кликабельны.

Повтор Подозрение Возможен Нет повтора
  • Нажмите на число в ячейке САПС/СКУД/ТСВ — развернутся тексты заявок
  • Экспорт XLSX и HTML, рассылка на почту
LLM · SQL-agent

Чат с базой данных

Вопросы на естественном языке → безопасные SQL (SELECT) → таблицы и графики ECharts.

  • «Построй круговую диаграмму health_status по регистраторам»
  • «Сделай столбчатый график систем по типам из АС Арсенал»
  • Read-only — запись в БД невозможна
rvr-repeat / export.html · interactive · клик по цифре в ячейке

AI только подсвечивает возможные проблемы (вердикт и цвет строки). Нажмите на число повторов по виду системы — откроются формулировки заявок для глубокого ручного анализа.
